PDF Do installer: return codes

Applies to PDFDoSetup.exe (EXE installer, x64), published by VIN TECHNOLOGIES.

Command-line switches

SwitchMeaning
/silentInstall without any window or prompt. Per-user install, no administrator rights, no restart.
/uninstallRemove PDF Do (use with /silent for no prompts). Normally run from Settings → Apps.

Return codes

CodeScenarioNotes
0SuccessInstalled (or removed) successfully.
1223Cancelled by the userThe user declined the uninstall confirmation.
1638Application already existsReserved. An existing PDF Do is upgraded in place, so this is not normally returned.
1618Another installation already in progressAnother PDF Do setup is running. Wait for it to finish and run again.
112Disk fullNot enough free space (about 450 MB needed).
3010Restart requiredReserved. PDF Do never needs a restart.
1625Rejected by a security policyWindows or an administrator policy blocked writing the files.
1603Other installation failureAny other error. Details are written to %LOCALAPPDATA%\PDFDo\setup-error.log.

The installer works completely offline, so it has no network-related failure codes.
